# OpenRouter Media APIs Documentation

OpenRouter's image generation, text-to-speech and speech-to-text APIs under `https://openrouter.ai/api/v1`, with the records of `google/gemini-nano-banana-2.1`, `openai/gpt-image-2.6-sunburst`, `openai/gpt-image-2.6-flare`, `openai/gpt-image-2.5-sunburst`, `openai/gpt-image-2.5-flare`, `bytedance-seed/seedream-5-0-flash`, `google/gemini-3.8-flash-tts`, `google/gemini-3.8-flash-lite-tts`, `fish-audio/drama-3`, `openai/gpt-transcribe` and `fish-audio/transcribe-1`.

## Notes

Captured 2026-11-04 and 2026-11-19 (`api_captures/openrouter_images/`, `openrouter_tts/`, `openrouter_stt/`, git-ignored):

- `POST /api/v1/images/generations` answers like `POST /api/v1/images`, so an OpenAI Images request with `prompt` and `size` (`1024x1024`, `2048x1152`) works. Seedream returns a JPEG as `b64_json` with `media_type: "image/jpeg"`; the `openai/gpt-image-*` models return PNG as `b64_json` with `media_type: "image/png"`. `usage` is `prompt_tokens`, `completion_tokens`, `total_tokens`, `cost` and details. `stream: true` on a non-streaming model is ignored, and the reply is the same JSON. A `size` that conflicts with `aspect_ratio` is a 400.
- Chat Completions with `modalities: ["image"]` and `image_config` also generates. The first chunk carries `delta.images[]` as `{"type": "image_url", "image_url": {"url": "data:image/jpeg;base64,..."}}` beside `content: ""`, then a `finish_reason: "stop"` chunk, then the usage chunk, then `[DONE]`. Without a size, it rendered 2048x2048.
- TTS works without `voice` on `fish-audio/drama-3` (Fish's default voice), whereas `google/gemini-3.8-flash-tts` and `google/gemini-3.8-flash-lite-tts` require an explicit voice (`"Kore"` by default in MMSP's `gemini` plugin for `openai-speech`; omitting `voice` returns `400 An explicit voice is required for this TTS provider.`). `pcm` arrives as `Content-Type: audio/pcm;rate=44100;channels=1` on Fish Audio and `Content-Type: audio/pcm;rate=24000;channels=1` on Gemini TTS (16-bit little-endian mono), and `mp3` as `audio/mpeg`. The bytes stream as they are made, with the first after about 0.7 s. The response carries no usage. `GET /api/v1/generation?id=<X-Generation-Id>` reports `total_cost` (69 bytes cost $0.000138 on Drama 3). An unknown voice is a bare `400 Provider returned 400`, and a `response_format` other than `mp3` or `pcm` is a 400 validation error.
- STT answers `{"text", "usage": {"seconds", "cost"}}` (8 s, $0.0008 for 7.6 s of audio on `fish-audio/transcribe-1`; 1 s, $0.000075 on `openai/gpt-transcribe`) to JSON `input_audio` (MP3 or WAV) and to multipart alike. `stream: true` is ignored.
