# Qwen3.8 27B replaces Qwen3.6 35B A3B on OpenRouter and SiliconFlow

- **Date:** 2026-10-01
- **Type:** feature
- **Scope:** `registry`, `docs`

[中文版](2026-10-01-qwen3-8.zh.md)

## What changed

- `list_supported_models` lists `qwen/qwen3.8-27b` on OpenRouter (`openai-responses`; 1M context; USD 0.42 / 3.00 per million input / output tokens, 0.085 cached) and `Qwen/Qwen3.8-27B` on SiliconFlow (`openai-chat`), in place of `qwen/qwen3.6-35b-a3b` and `Qwen/Qwen3.6-35B-A3B`. SiliconFlow publishes no context window or price for it, so its entry carries neither.
- The README's model table and SiliconFlow example, the site's gateway example and the slow e2e tests use Qwen3.8 27B.

## Compatibility

- The Qwen3.6 ids still work with any client type; only the registry no longer lists them. The vLLM adapter keeps its Qwen3.6 thinking profile.
