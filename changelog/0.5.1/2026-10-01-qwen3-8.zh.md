# OpenRouter 与 SiliconFlow 上的 Qwen3.6 35B A3B 换成 Qwen3.8 27B

- **Date:** 2026-10-01
- **Type:** feature
- **Scope:** `registry`, `docs`

[English](2026-10-01-qwen3-8.md)

## 变更内容

- `list_supported_models` 列出 OpenRouter 上的 `qwen/qwen3.8-27b`（`openai-responses`；上下文 1M；每百万 token 输入 / 输出 0.42 / 3.00 美元，缓存命中 0.085 美元）和 SiliconFlow 上的 `Qwen/Qwen3.8-27B`（`openai-chat`），取代 `qwen/qwen3.6-35b-a3b` 与 `Qwen/Qwen3.6-35B-A3B`。SiliconFlow 没有公布该模型的上下文长度和价格，所以条目里不写这两项。
- README 的模型表和 SiliconFlow 示例、站点的网关示例以及慢速 e2e 测试都改用 Qwen3.8 27B。

## 兼容性

- Qwen3.6 的模型 id 在任何客户端类型下仍可使用，只是注册表不再列出。vLLM 适配器保留 Qwen3.6 的思考配置。
