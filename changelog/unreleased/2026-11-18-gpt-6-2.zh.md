# GPT-6.2 Astra 与 GPT-6.2 Sol

- **Date:** 2026-11-18
- **Type:** feature
- **Scope:** `openai-official`, `openai-responses`, `registry`
- **PR:** [#344](https://github.com/Prism-Shadow/model-message-stream-protocol/pull/344)

[English](2026-11-18-gpt-6-2.md)

## 变更内容

- `openai-official` 把 `gpt-6.2-astra` 与 `gpt-6.2-sol` 作为 GPT-6 模型提供服务，`openai-responses` 通过其 `gpt` 插件在 OpenRouter 上提供 `openai/gpt-6.2-astra` 与 `openai/gpt-6.2-sol`：两个模型都拒绝 `none` 与 `minimal` 思考档位，因此 `ThinkingLevel.NONE` 以 `low` 运行；`openai-official` 上 `prompt_caching` 的 `enhance` 发送 `prompt_cache_options: {"ttl": "12h"}`；超过 30,000 个 patch 的图片以 `detail: "high"` 发送。
- 注册表新增四个条目，输入文本与图片、输出文本，上下文 1,050,000 token：GPT-6.2 Astra 每百万 token 提示 $10（30 分钟缓存写入价）、缓存 $0.40、回复 $40，GPT-6.2 Sol 为 $2.50、$0.10 与 $10，OpenAI 与 OpenRouter 相同。注册表共 368 个条目。
- 共享测试目录在 `openai-official` 上以 `gpt-6.2-sol` 取代 `gpt-6.1-sol`。
- `llmsdk_docs/gpt6/` 新增 GPT-6.2 的模型页面，并按 developers.openai.com 刷新了 GPT-6 的页面与指南。
