# GPT-6.1 Terra，以及 GPT-6 上的 allowed-tools 列表、超大图片与 12 小时缓存

- **Date:** 2026-11-02
- **Type:** feature
- **Scope:** `openai_official`, `openai_responses`, `utils`, `registry`, `tests`
- **PR:** [#313](https://github.com/Prism-Shadow/model-message-stream-protocol/pull/313)

[English](2026-11-02-gpt-6-1-terra.md)

## 变更内容

- 两个包中注册了 `gpt-6.1-terra`（OpenAI，`openai-official`）与 `openai/gpt-6.1-terra`（OpenRouter，`openai-responses`）。它加入了共享的模型测试目录，OpenRouter 用例标为 slow，它的文档快照保存在 `llmsdk_docs/gpt6/`。
- `openai-official` 与 `openai-responses` 在 GPT-6.1 Terra 上把 `ThinkingLevel.NONE` 发成 `reasoning.effort: "none"`；GPT-6 Astra 与 GPT-6.1 Sol 仍为 `low`。
- `tool_choice` 为工具名列表时，`openai-official` 与 `openai-responses` 在 `mode: "required"` 和工具列表之外加上了 `type: "allowed_tools"`。`openai-chat` 保持不变。
- `openai-official`、`openai-responses` 与 `openai-chat` 对 GPT-6 也像对 GPT-5.6 一样，在超过 30,000 个 patch 的图片上发送 `detail: "high"`。
- `openai-official` 在 GPT-5.6 与 GPT-6 上把 `prompt_caching: "enhance"` 发成 `prompt_cache_options: {"ttl": "12h"}`。`disable`，以及更早 GPT 模型上的 `enhance`，抛出 `UnsupportedParameterError`，错误信息改为新的措辞；`openai-responses` 与 `openai-chat` 对两者仍然抛错。
- 从 developers.openai.com 刷新了 `llmsdk_docs/openai_responses/docs/openai-responses-create.md` 和两份 fast mode 快照；`llmsdk_docs/gpt6/` 新增了价格页与图片输入指南。

## 配置行为

| 键 | 客户端与模型 | 发送 |
| --- | --- | --- |
| `thinking_level: "none"` | `openai-official`、`openai-responses`：GPT-6.1 Terra | `reasoning.effort: "none"` |
| `tool_choice: [工具名]` | `openai-official`、`openai-responses` | `{"type": "allowed_tools", "mode": "required", "tools": [{"type": "function", "name": ...}]}` |
| `prompt_caching: "enhance"` | `openai-official`：GPT-5.6、GPT-6 | `prompt_cache_options: {"ttl": "12h"}` |
| 超过 30,000 个 patch 的图片 | `openai-official`、`openai-responses`、`openai-chat`：GPT-5.6、GPT-6 | `detail: "high"` |

12 小时的缓存写入按 30 分钟写入价格的两倍计费；缓存写入计入 `prompt_tokens`。
