# 状态卡片以上次和下次探测为主

- **Date:** 2026-10-25
- **Type:** feature
- **Scope:** `site`
- **PR:** [#304](https://github.com/Prism-Shadow/model-message-stream-protocol/pull/304)

[English](2026-10-25-status-probe-times.md)

## 变更内容

- `/status/` 与 `/zh/status/` 的总览卡片在色带下方显示两项带标签的数值：上次探测，以及下次探测（预计）。每项是一个本地时间，如 `10月25日 17:18`，旁边附相对时间，每分钟更新一次；提示框里是完整的日期、时间和时区。上次探测链接到它在 GitHub 上的那次运行；下次探测按 `status.yml` 的定时推算，标为预计。还没有探测时两项都显示 `—`，工作流不是每天固定一次的定时时，下次探测保持 `—`。两项从首次绘制起就占好了位置。
- 本月的探测费用和次数原先以 `text-2xl` 显示在卡片右侧，改为卡片底部的一行灰色小字，如 `本月探测费用 $0.031 · 3 次`。原先列在下面的此前各月移入这行的提示框，最新的在前，每月附费用和次数。
- `site/src/shared/i18n.ts` 的状态文案以 `lastProbe`、`nextProbe` 和 `cost` 取代 `checked`、`next` 和 `month`，中英文都已修改。
- 卡片在构建时就为色带文字和底部小字留出位置，脚本填入内容时卡片不再变高。
