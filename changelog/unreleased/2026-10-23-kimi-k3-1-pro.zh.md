# Kimi K3.1 Pro

- **Date:** 2026-10-23
- **Type:** feature
- **Scope:** `moonshot_official`, `registry`, `ci`, `docs`

[English](2026-10-23-kimi-k3-1-pro.md)

## 变更内容

- `kimi-k3.1-pro` 与 `kimi-k3.1-pro-highspeed`：`MoonshotOfficialClient` 在 Python 和 TypeScript 中支持这两个模型，请求格式与 Kimi K3 相同。
- `thinking_level: none`：在 K3 系列（包括 `kimi-k3`）上，`MoonshotOfficialClient` 发送 `reasoning_effort: "none"`，此前发送 `"low"`。
- `prompt_caching: enhance`：在 K3 系列上，`MoonshotOfficialClient` 发送 `prompt_cache_options: {"mode": "implicit", "ttl": "1h"}`，此前抛出 `UnsupportedParameterError`。所有 Kimi 模型上的 `disable` 与 Kimi K2 上的 `enhance` 仍然抛错，错误信息为 `Kimi does not support this prompt_caching (disable has no equivalent; enhance needs Kimi K3).`
- 注册表：登记 Moonshot 的 `kimi-k3.1-pro` 与 `kimi-k3.1-pro-highspeed`、OpenRouter 的 `moonshotai/kimi-k3.1-pro` 和 TokenDance 的 `kimi-k3.1-pro`；OpenRouter 上 `moonshotai/kimi-k3` 的输出价格由 11.936 美元更正为 10.8 美元。
- `.github/ci/models.json`：`moonshot-official` 组改为测试 `kimi-k3.1-pro` 与 `moonshotai/kimi-k3.1-pro`，取代 `kimi-k3` 与 `moonshotai/kimi-k3`。
- 配置页把 Kimi K3 与 K3.1 Pro 列入原样接受 `"none"` 的模型，并给出它们的 `thinking_level` 行与 `prompt_caching` 行；模型页在 `moonshot-official` 下列出 `kimi-k3.1-pro` 与 `kimi-k3.1-pro-highspeed`；README 的 Kimi 行加入 K3.1 Pro，示例 id 改为 `kimi-k3.1-pro`。
- Playground 的 Kimi 选项改为 `kimi-k3.1-pro`（Kimi K3.1 Pro）。
- 新增 `llmsdk_docs/kimi_k3_1/` 文档快照，并更新 `llmsdk_docs/kimi_k3/`。

## 配置行为

| `UniConfig` | `moonshot-official` 上的 K3 系列（`kimi-k3`、`kimi-k3.1-pro`、`kimi-k3.1-pro-highspeed`） |
| --- | --- |
| `thinking_level: none` | `reasoning_effort: "none"` |
| `thinking_level: low` | `"low"` |
| `thinking_level: medium` / `high` | `"high"` |
| `thinking_level: xhigh` / `max` | `"max"` |
| `tool_choice: "auto"` / `"none"` / `"required"` | 原值 |
| 指定工具名的 `tool_choice` | `UnsupportedParameterError` |
| 未设置 `prompt_caching` 或设为 `enable` | 不发送 |
| `prompt_caching: enhance` | `prompt_cache_options: {"mode": "implicit", "ttl": "1h"}` |
| `prompt_caching: disable` | `UnsupportedParameterError` |
